# Student Registration System

## About the Project

The Student Registration System is a software application developed to simplify and manage the student registration process. It allows users to enter, store, view, update, and manage student information digitally.

The main purpose of this project is to reduce manual paperwork, improve data organization, and make student record management easier and more efficient.

## Features

- Add new student records.
- View registered student details.
- Update existing student information.
- Delete student records.
- Manage student registration data.
- Simple and user-friendly interface.

## Technologies Used

- Programming Language:
- Frontend: Html, Css, Javascript
- Backend: Python-Flask
- Database: Mysql
